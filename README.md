# Luna Store

Sitio de [@lunastore_mat](https://www.instagram.com/lunastore_mat/) — Tienda Online, Maturín.
Productos importados de EE. UU. a Venezuela: bisutería, accesorios y fragancias.

Las fotos de producto en `assets/productos/` sirven además como origen de imagen
para la publicación automática en Instagram, que exige una URL pública.
